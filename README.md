# Real-Time Chat & Collaboration System

A full-stack real-time chat and collaboration application built using the MERN stack.

## Tech Stack

### Frontend
- React
- React Router
- Axios
- Socket.IO Client

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Socket.IO

## Features

- User registration and login
- JWT authentication
- User search
- One-to-one conversations
- Real-time messaging
- Online/offline status
- Typing indicators
- Read/unread messages
- Group conversations
- Message notifications
